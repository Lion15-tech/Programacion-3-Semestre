# Programación - 3.er semestre

Repositorio de ejercicios y proyectos realizados durante el tercer semestre de programación. Incluye prácticas de programación orientada a objetos, NumPy y Tkinter.

## Contenido

- `Ejercicios_Clases_01` y `Ejercicios_Clases_02`: ejercicios de programación orientada a objetos.
- `Numpy`: prácticas con la biblioteca NumPy.
- `Tkinter`: ejercicios y proyectos de interfaces gráficas.
- `Extras`: material y archivos complementarios.

## Proyecto de base de datos para gimnasio

En [`Tkinter/Ejercicios_Tarea/Proyecto_Base_de_Datos`](Tkinter/Ejercicios_Tarea/Proyecto_Base_de_Datos) se encuentra una aplicación de escritorio en Python con una ventana principal para navegar por las secciones de clientes, estado y tipo de membresía, inversión e instalaciones.

La aplicación utiliza Tkinter para la interfaz y SQLite, incluido en la biblioteca estándar de Python. Al iniciar, el módulo de base de datos crea la tabla `clientes` si todavía no existe. El proyecto está en desarrollo; las ventanas y formularios disponibles no implican que todas las operaciones de gestión de datos estén implementadas.

### Requisitos

- Python 3
- Tkinter disponible en la instalación de Python

No se requieren paquetes externos para ejecutar el proyecto.

### Ejecución

Desde la raíz del repositorio, abre una terminal y ejecuta:

```powershell
cd Tkinter\Ejercicios_Tarea\Proyecto_Base_de_Datos
python main.py
```

Inicia la aplicación desde la carpeta del proyecto para que SQLite cree o encuentre allí el archivo de base de datos usado por el programa.
